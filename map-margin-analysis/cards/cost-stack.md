# Cost Stack   (live)

**Source:** table `tblEXAMPLE0000007`.
**What it is:** what the build costs, kept in two parallel systems that do not agree with each other and feed different margin lines. Knowing which is which is most of this card's job.
**Shape (base A, typed by hand):** `Land Cost` (`fldEXAMPLE0000014`) · `House Costs` (`fldEXAMPLE0000015`) · `Extras Costs` (`fldEXAMPLE0000016`) → `Total Costs` (`fldEXAMPLE0000017`). This is the base the headline margin chain runs on: Gross Margin $ (Pre Soft Costs) through Final Projected Margin (cards/margin-stack.md).
**Shape (base B, derived from sq ft):** the Smart pattern (a typed override wins, else the Model lookup): main floor `fldEXAMPLE0000018`, upper floor `fldEXAMPLE0000019`, cost per sq ft `fldEXAMPLE0000020`. `Total Sq Ft` (`fldEXAMPLE0000021`) = main + upper only. `House Cost` (`fldEXAMPLE0000022`) = cost per sq ft × Total Sq Ft; `Extras Cost` (`fldEXAMPLE0000023`) = 70% of retail extras; those plus the manual `Land Cost` → `Total Construction Costs` (`fldEXAMPLE0000024`) → the plain `Gross Margin $` (`fldEXAMPLE0000025`) and `Gross Margin %` (`fldEXAMPLE0000026`).
Also on this card: the mark-up readouts: house `fldEXAMPLE0000027` / `fldEXAMPLE0000028`, extras `fldEXAMPLE0000029` / `fldEXAMPLE0000030`, land `fldEXAMPLE0000031` / `fldEXAMPLE0000032`, total-% `fldEXAMPLE0000033`. The land mark-up input has never held a non-zero value, so its percent is 0 in all 347 records. And the near-twin trap: `fldEXAMPLE0000034` ("Gross Margin (pre-soft Costs)") is house-only on base B. It is NOT `fldEXAMPLE0000035` ("Gross Margin $ (Pre Soft Costs)"), which is whole-deal on base A.
**Hits:** editing the manual `House Costs` / `Extras Costs` / `Land Cost` moves the Final Projected Margin chain. Editing the Model or the sq-ft overrides moves only the plain Gross Margin pair and the mark-up readouts. A typed override freezes that record against future Model changes.
**Does not hit:** `Basement Sq Ft` (`fldEXAMPLE0000036`) and the Smart garage figure (`fldEXAMPLE0000037`) feed no formula. Total Sq Ft is main + upper, so basement and garage edits change no cost anywhere. `Total Livable Sq Ft` (`fldEXAMPLE0000038`) is a duplicate of Total Sq Ft, not a third system.
