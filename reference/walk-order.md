# Walk order

The order a cold reader should meet the nouns: front door first, then the spine, then the edges. A reader who wants one noun jumps straight to its card from the catalog. This order is only for someone reading more than one.

For the Render Factory slice (worked example in `examples.md`):

1. **Catalog** (front door)
2. **Homeowner Portal Render Variants** — the spine; the thing the factory produces
3. **Homeowner Portal Selections** — what drives a variant
4. **Home Photography Assets** — the reference input; also the attach point for planned changes
5. **Catalogue Items / Categories / Packages** — the menu behind a selection (shape only)
6. **Ghosts and the wrong neighbour (Documents)** — last, as warnings
